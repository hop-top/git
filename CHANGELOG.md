## [0.1.0-alpha.2](https://github.com/hop-top/git/compare/v0.1.0-alpha.1...v0.1.0-alpha.2) (2026-09-26)


### ⚠ BREAKING CHANGES

* **cli:** GIT_HOP_* vars other than GIT_HOP_VERBOSE no longer stand in for global flags. Previously undocumented and partly effective: the result settings (GIT_HOP_OUTPUT, GIT_HOP_COLS, GIT_HOP_TEMPLATE) applied; GIT_HOP_QUIET, GIT_HOP_FORMAT, GIT_HOP_NO_COLOR and GIT_HOP_OFFLINE did not. Pass the flag instead. Explicitly read vars (GIT_HOP_DATA_HOME, GIT_HOP_AUTO_ENV_START, GIT_HOP_HOOKS, GIT_HOP_ADD_FROM, ...) unchanged.
* **state:** GIT_HOP_REPO_ID and the repository keys in state.json now carry the origin's host (<host>/<org>/<repo>) instead of a fixed github.com. Both change for any repository whose origin is not on github.com, and for a local origin they follow hop.gitDomain. Hooks that match GIT_HOP_REPO_ID against a github.com/<org>/<repo> value need updating.
* **config:** -c/--config no longer loads a config file or key=value overrides, and $XDG_CONFIG_HOME/git-hop/config.json is not read. Keys it did reach (output, cols, template, format-opt, verbose) stop applying; a missing -c file now exits 0 instead of 129.
* **state:** state.json format 2.0.0; older releases read it with paths where branches were, and their edits are re-migrated on next load
* **env:** add and clone start the new worktree's environment only for hop.env.autoStart=true, GIT_HOP_AUTO_ENV_START=true or --env-start. hop.autoEnvStart is ignored; set hop.env.autoStart instead.
* **env:** hop.autoEnvStart now acts. A true value in git config (set by hand, or written by earlier shell-integration installs, which persisted every default) makes add and clone run the environment start. GIT_HOP_AUTO_ENV_START=detect, formerly documented, is now fatal.
* **gitflow:** in repos with gitflow.initialized=true, git hop add/remove no longer run `git flow <type> start|finish` (finish merged into the parent branch). Opt back in per repo with `git config hop.gitflow.enabled true`, or for all repos with `git config --global hop.gitflow.enabled true`.
* **deps:** --verbose semantics changed.
